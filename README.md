# Система управления личными финансами

## Описание
Данный проект реализует простое консольное backend-приложение для управления личными финансами. Пользователь может регистрироваться, авторизовываться, создавать кошельки, добавлять доходы и расходы, устанавливать бюджеты по категориям, просматривать статистику и производить переводы между кошельками.

---

## Как пользоваться сервисом

1. Запустите программу командой:  
java myapp.FinanceApp или через IDE с настройками запуска класса `FinanceApp`.

2. При первом запуске используйте команду `register` для создания нового пользователя:  
- Введите имя пользователя и пароль.

3. Авторизуйтесь с помощью команды `login` с введёнными логином и паролем.

4. После входа доступны команды управления финансами через главное меню:
- `wallet` — создать новый кошелек
- `add_income` — добавить доход в выбранный кошелек
- `add_expense` — добавить расход в выбранный кошелек
- `add_budget` — установить бюджет по категории для выбранного кошелька
- `report` — вывести отчет по доходам, расходам и бюджетам
- `transfer` — перевод средств между кошельками
- `logout` — выйти из аккаунта

---

## Поддерживаемые команды

### В главном меню:
- `register` — регистрация нового пользователя
- `login` — вход в систему
- `exit` — выход из программы

### В меню пользователя:
- `wallet` — создать кошелек (укажите имя)
- `add_income` — добавить доход (укажите кошелек, сумму, категорию, описание)
- `add_expense` — добавить расход (укажите кошелек, сумму, категорию, описание)
- `add_budget` — установить бюджет (укажите кошелек, категорию, сумму бюджета)
- `report` — вывести отчет по выбранному кошельку
- `transfer` — перевести деньги с одного кошелька на другой (укажите оба кошелька, сумму, категорию, описание)
- `logout` — выйти в главное меню

---

## Как протестировать код

1. Скомпилируйте проект (если используете командную строку):  
javac src/myapp/*.java

2. Запустите главный класс:  
java -cp src myapp.FinanceApp

3. Пройдите регистрацию нового пользователя и выполните вход.

4. Создайте кошелек, добавьте доходы и расходы с категориями.

5. Проверьте отчет и корректность расчетов.

6. Выполните перевод между кошельками, выход и повторный вход.
